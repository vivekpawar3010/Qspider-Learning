Video Tag

Definition
The <video> tag is used to embed video content in an HTML document. It supports various attributes to control playback, appearance, and behavior. Videos can be in formats like MP4, WebM, or OGV.
src
Specifies the source URL of the video file. It can be a local path or an online link. Multiple <source> tags can be used for different formats.
height & width
Control the dimensions of the video player in pixels or percentages.
controls
Adds playback controls like play, pause, volume, and progress bar to the video player.
autoplay
Automatically starts playing the video when the page loads. Note: Many browsers block autoplay without user interaction.
muted
Starts the video with sound muted. Useful with autoplay to avoid browser restrictions.
loop
Restarts the video automatically after it finishes playing.
poster
Displays a placeholder image while the video is loading or before playback starts.
preload
Specifies how the video should be loaded: "none" (no preload), "metadata" (load metadata only), "auto" (load entire video).

Embedding Websites

Definition
Embedding allows you to include external content like videos, maps, or other websites directly into your HTML page using the <iframe> tag. This creates an inline frame within your document.
src
Specifies the URL of the content to embed, such as a YouTube video or Google Maps.
width & height
Define the dimensions of the embedded content in pixels.
frameborder
Controls whether a border is displayed around the iframe. Value "0" removes the border.
allow
Specifies permissions for the embedded content, such as "accelerometer", "autoplay", "fullscreen", etc.
allowfullscreen
Allows the embedded content to be displayed in fullscreen mode when supported.
title
Provides a title for the iframe, improving accessibility for screen readers.
loading
Controls when the iframe content loads: "lazy" (load when needed) or "eager" (load immediately).

Audio Tag

Definition
The <audio> tag is used to embed audio content in an HTML document. It supports various attributes to control playback and appearance. Audio files can be in formats like MP3, WAV, or OGG.
src
Specifies the source URL of the audio file. It can be a local path or an online link. Multiple <source> tags can be used for different formats.
controls
Adds playback controls like play, pause, and volume to the audio player.
autoplay
Automatically starts playing the audio when the page loads. Note: Many browsers block autoplay.
muted
Starts the audio with sound muted.
loop
Restarts the audio automatically after it finishes.
preload
Specifies how the audio should be loaded: "none", "metadata", or "auto".
volume
Sets the initial volume level (0.0 to 1.0), though it's not widely supported.

Elements

Definition
HTML elements are the building blocks of web pages. They consist of an opening tag, content, and a closing tag. Elements can be block-level or inline.

Block Elements

Definition
Block elements always start on a new line and take up the full width available. They create a "block" of content.
Examples
<h1>-<h6> (headings), <div> (division), <p> (paragraph), <ol> (ordered list), <ul> (unordered list), <table> (table), etc.
Characteristics
They stack vertically, can contain other block or inline elements, and have default margins/padding.

Inline Elements

Definition
Inline elements do not start on a new line and only take up as much width as necessary. They flow within the text.
Examples
<span> (generic inline container), <a> (anchor/link), <strong> (strong emphasis), <em> (emphasis), <img> (image), <br> (line break), etc.
Characteristics
They appear in the flow of text, cannot contain block elements, and respect text formatting.

Attributes

Definition
Attributes provide additional information about HTML elements. They are always placed inside the opening tag and usually come in key-value pairs, e.g., height="100px". Attributes modify the behavior or appearance of elements.
Purpose
Used to give properties to tags/elements, control functionality, styling, and accessibility.

Types of Attributes

Core/Global Attributes

Attributes that can be used in any HTML element.

id
Provides a unique identifier for an element, used for styling, scripting, and linking.
class
Assigns one or more class names to an element for styling and grouping.
style
Applies inline CSS styles directly to an element.
title
Provides additional information displayed as a tooltip on hover.
height & width
Specify the dimensions of the element (for applicable elements like images, videos).
hidden
A boolean attribute that hides the element from view.
lang
Specifies the language of the element's content for accessibility and styling.
tabindex
Controls the tab order for keyboard navigation.
contenteditable
Makes the element's content editable by the user.

Element-Specific Attributes

Attributes that are used only with specific elements.

href
Used with <a> tags to specify the destination URL of a link.
src
Used with media elements like <img>, <video>, <audio> to specify the source path.
alt
Provides alternative text for <img> elements if the image fails to load.
type
In <input> tags, specifies the input type (e.g., text, password, email).
value
Sets the default value in form inputs or the value of buttons.
target
Used with <a> tags to specify where to open the linked document.
placeholder
Provides hint text in input fields that disappears when typing.
required
Makes a form field mandatory for submission.

Anchor Tag

Definition
The <a> tag, or anchor tag, is used to create hyperlinks in web pages. It allows navigation between pages or sections.
href
Specifies the destination URL of the link. Can be absolute (external site) or relative (within the same site).
target
Specifies where to open the linked document. Values: "_blank" (new tab), "_self" (same tab), "_parent", "_top".
title
Provides additional information about the link, displayed as a tooltip on hover.
rel
Specifies the relationship between the current document and the linked document. Values like "noopener", "noreferrer" for security.
download
Causes the browser to download the linked resource instead of navigating to it.
