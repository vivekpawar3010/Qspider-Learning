    Anchor Tag

    1. Def- Anchor tag is used to create the link in the web page.
    2. herf- used to specify the destination URL of the link. It can be an absolute URL (linking to an external website) or a relative URL (linking to another page within the same website).
    3. target- used to specify where to open the linked document. Common values include "_blank" (opens in a new tab), "_self" (opens in the same tab), "_parent" (opens in the parent frame), and "_top" (opens in the full body of the window).
    4. title- used to provide additional information about the link, which is typically displayed as a tooltip when the user hovers over the link.
    5. rel- used to specify the relationship between the current document and the linked document. Common values include "noopener" and "noreferrer" for security purposes when using target="_blank".
    6. tel- used to specify the telephone number for the link.
