HTML Basics

History of HTML

HTML stands for HyperText Markup Language. It was created by Tim Berners-Lee in 1991 to structure content on the web. HTML is the standard language used to build web pages and applications.

Created by / Used for

Created by
Tim Berners-Lee at CERN.
Used for
Structuring web content using tags to define headings, paragraphs, links, images, lists, tables, and forms.

HTML Versions

  • HTML 1.0 - First version published in 1991.
  • HTML 2.0 - Standardized version in 1995.
  • HTML 3.2 / 4.0 - Added more tags and layout features.
  • HTML5 - Current major version, introduced modern semantic tags and multimedia support.

Main Tags

The main HTML tags create the page structure and content. Basic tags include:

  • <html> - Root element of an HTML document.
  • <head> - Contains metadata, title, and links to styles/scripts.
  • <title> - Sets the browser tab title.
  • <meta> - Provides page metadata like charset and viewport.
  • <body> - Contains the visible page content.
  • <h1>–<h6> - Heading tags.
  • <p> - Paragraph text.
  • <a> - Hyperlink anchor tag.
  • <img> - Embeds images.
  • <ul>, <ol>, <li> - List tags.
  • <table>, <tr>, <th>, <td> - Table tags.
  • <form>, <input>, <label>, <textarea>, <select> - Form tags.
  • <div> - Block-level container.
  • <span> - Inline container.
  • <header>, <nav>, <div>, <article>, <footer>, <aside> - Semantic diving tags.

Basic HTML Tag Definitions

<html>
The root element of an HTML page.
<head>
Contains metadata, page title, styles, and scripts.
<title>
Defines the page title shown in the browser tab.
<meta charset="UTF-8">
Specifies the character encoding of the document.
<meta name="viewport" content="width=device-width, initial-scale=1.0">
Ensures the page scales correctly on mobile devices.
<body>
Contains all the visible content of the page.
<h1>–<h6>
Heading tags; <h1> is the most important and <h6> is the least important.
<p>
Represents a paragraph of text.
<a href="...">
Defines a hyperlink to another page or resource.
<img src="..." alt="...">
Displays an image and requires the src and alt attributes.
<ul>
Creates an unordered (bulleted) list.
<ol>
Creates an ordered (numbered) list.
<li>
Defines an item inside a list.
<dl>, <dt>, <dd>
Defines a description list with terms and definitions.
<table>
Creates a table to display tabular data.
<tr>
Defines a row in a table.
<th>
Defines a table header cell.
<td>
Defines a table data cell.
<form>
Groups input controls for submitting data.
<input>
Creates a single-line input field for text, email, password, radio, checkbox, file, and more.
<label>
Labels a form control and improves accessibility.
<textarea>
Creates a multi-line text input area.
<select>
Creates a drop-down list.
<option>
Defines an option inside a select menu.
<optgroup>
Groups related options inside a select menu.
<button>
Represents a clickable button.
<div>
A block-level container used for grouping content.
<span>
An inline container used for styling small pieces of text.
<header>
Defines an introductory div for a page or div.
<nav>
Defines navigation links.
<div>
Defines a thematic div of content.
<article>
Defines self-contained content such as a blog post or news article.
<aside>
Defines content related to the main content, like a sidebar.
<footer>
Defines a footer for a div or page.

Image Tag and URL Types

The <img> tag embeds images into a page.

src
Specifies the image file URL.
alt
Provides alternative text if the image cannot load.
Absolute URL
A full path to an image, including protocol and domain, such as https://example.com/images/photo.jpg.
Relative URL
A path relative to the current page, such as images/photo.jpg or ../images/photo.jpg.
