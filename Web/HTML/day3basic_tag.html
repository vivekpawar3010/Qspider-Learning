List Tags

Definition
A list is a collection of items that can be displayed in an ordered or unordered manner.
Ordered List
A list where items are numbered in a specific order.
Unordered List
A list where items are displayed without any specific numbering.
Definition List
A list of terms and their definitions.

There are 3 Types of Lists:

  • Ordered List (<ol>): A list where items are numbered in a specific order.
  • Unordered List (<ul>): A list where items are displayed with bullets.
  • Definition List (<dl>): A list of terms and their definitions.

Characteristics of Ordered Lists

  1. type: Defines the type of numbering to start the elements.
    1
    Numbers (1, 2, 3, ...)
    A
    Uppercase letters (A, B, C, ...)
    a
    Lowercase letters (a, b, c, ...)
    I
    Uppercase Roman numerals (I, II, III, ...)
    i
    Lowercase Roman numerals (i, ii, iii, ...)
  2. start: Specifies the starting number for the list.
  3. reversed: Reverses the numbering order.

Characteristics of Unordered Lists

  • type: Defines the bullet style.
    • type="disc" (default): Solid circle
    • type="circle": Hollow circle
    • type="square": Square

Table Tag

Definition
A table is a combination of rows and columns used to display data in a structured format.
<table>
The main tag to create a table.
<thead> & <tbody>
Help to group header and body rows for better structure and styling.
<tr>
Defines a table row.
<th>
Defines a table header cell (bold and centered by default).
<td>
Defines a table data cell.
border
Adds a border to the table (e.g., border="1").
border-collapse
CSS property to collapse borders (border-collapse: collapse).
colspan
Allows a cell to span multiple columns.
rowspan
Allows a cell to span multiple rows.

Form Tag

Definition
A form is a section of a document that contains interactive controls for submitting information to a web server.
<form>
The main tag to create a form. It can contain various input elements like text fields, checkboxes, radio buttons, etc.
action
Specifies the URL where the form data will be sent when submitted.
method
Specifies the HTTP method to use when submitting the form (e.g., GET or POST).
Some other tags and attributes
<label> - Associates a text label with a form control. Use the for attribute to link it to an input ID.
<input> - Creates single-line controls such as text, email, password, radio, tel, and file inputs.
<select> - Creates a drop-down list of options.
<optgroup> - Groups related options inside a select list.
<textarea> - Creates a multi-line text field.
value - Defines the input's initial value.
readonly - Makes the input non-editable.
placeholder - Shows hint text inside the input before the user types.
type="file" - Creates a file selection control for uploads.
disabled - Disables the control so it cannot be used or submitted.
