Destructuring

Destructuring is a JavaScript expression that allows you to unpack values from arrays, or properties from objects, directly into distinct variables. It acts as a shortcut to extract data and drastically reduces repetitive code.

1. Object Destructuring.:-

Unpacks object properties into variables matching the property names

const user = { name: "John", age: 30 }; const { name, age } = user; console.log(name); // John

2. Array Destructuring:-

Unpacks array elements into variables based on their exact index position

const colors = ["red", "blue"]; const [first, second] = colors; console.log(second); // blue
