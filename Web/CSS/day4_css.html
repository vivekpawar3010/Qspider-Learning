CSS - Cascade Style Sheets

History of CSS

1994
CSS was first proposed by Håkon Wium Lie while working at CERN.
1996
CSS Level 1 (CSS1) was released with basic styling features.
1998
CSS Level 2 (CSS2) introduced positioning, z-index, and media types.
2011+
CSS3 moved to a modular format, adding transitions, animations, flexbox, and responsive design.
Today
CSS continues to grow with new modules and browser support for modern layout techniques.

Types of CSS

Inline CSS
Applied directly to an HTML element using the style attribute.
Example: <p style="color: red; font-size: 20px;">Text</p>
Inline CSS has the highest specificity and can override other styles.
Use it only for quick fixes or temporary testing, because it mixes content and presentation.
Internal CSS
Written inside a <style> block in the HTML <head>.
Example: <style> p { color: blue; } </style>
Internal CSS applies to the entire page and is useful for page-specific styling.
It is easier to manage than inline CSS but still stays inside the HTML file.
External CSS
Stored in a separate .css file and linked using the <link> tag.
Example: the current page uses ./day4_css.css.
External CSS is best for multi-page websites and cleaner HTML code.
It improves maintainability, reuse, and performance.
To increase rule importance: use !important, higher specificity, or IDs.

How HTML connects to CSS

The HTML file connects to an external CSS file using the <link> tag:

<link rel="stylesheet" href="./day4_css.css">

This line is placed inside the <head> section. It tells the browser to load the CSS file and apply its rules to the page.

External CSS is the best choice for larger websites because the same stylesheet can style multiple pages.

Selectors

Selectors tell CSS which HTML elements should receive style rules.

Element Selector
Targets all elements of a given tag. Example: p { color: green; } affects every paragraph.
Class Selector
Targets elements with a specific class. Example: .highlight { font-weight: bold; }.
ID Selector
Targets a single element with a unique ID. Example: #main-title { font-size: 28px; }.
Group Selector
Targets multiple selectors at once. Example: h1, h2, p { margin: 0; }.
Pseudo-class Selector
Targets an element state like :hover, :focus, or :active.
Combinator Selector
Targets elements based on relationships, such as div p or ul > li.

Display Property

The display property defines how an element is rendered in the layout.

display: block;
Block elements take up the full width and start on a new line. Example: div, p.
display: inline;
Inline elements stay on the same line and only take as much width as needed. Example: span, a.
display: inline-block;
Inline-block elements act like inline elements but allow width and height to be set.
display: none;
Hides the element completely. It does not appear and does not occupy space.
display: flex;
Creates a flexible container to align and distribute space among items.
